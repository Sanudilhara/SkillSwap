# Project structure

The frontend and backend are independent npm applications. There are no workspaces,
shared packages, custom hooks, state libraries, or service layers in Phase 1.

## Frontend

- `package.json`: React, React Router, and Vite dependencies and scripts; both
  `npm run dev` and `npm start` run the frontend development server.
- `package-lock.json`: exact dependency versions generated by npm.
- `.gitignore`: frontend dependency, build, and environment exclusions.
- `index.html`: HTML document and React root element.
- `vite.config.js`: React plugin and local development host/port.
- `src/main.jsx`: mounts React and wraps the application in BrowserRouter.
- `src/App.jsx`: shared header, navigation, routes, footer, and missing-page fallback.
- `src/pages/HomePage.jsx`: initial landing page.
- `src/pages/AboutPage.jsx`: short project introduction.
- `src/index.css`: plain CSS for layout, navigation, and responsive styling.

React Router uses the standard declarative BrowserRouter, Routes, Route, and Link
components. Future static hosting will need to send frontend routes to index.html.

## Backend

- `package.json`: ES modules, Express, dotenv, nodemon, and run/test scripts.
- `package-lock.json`: exact dependency versions generated by npm.
- `.gitignore`: backend dependency, environment, and test-output exclusions.
- `.env.example`: committed example containing PORT=4000.
- `.env`: ignored local configuration copied from the example.
- `src/app.js`: Express application, JSON middleware, and GET /api/health.
- `src/server.js`: loads environment variables and starts the local HTTP listener.
- `src/app.test.js`: HTTP integration test using Node's built-in test runner.

Keeping app.js separate lets the test start an isolated server on an available
port without loading local configuration or occupying the development port.

## Root and documentation

- `README.md`: project overview, setup, structure, and commands.
- `.gitignore`: common dependency, build, cache, environment, and editor exclusions.
- `docs/README.md`: documentation index.
- `docs/setup/local-development.md`: detailed setup and troubleshooting.
- `docs/architecture/project-structure.md`: this file inventory.
- `docs/api/README.md`: endpoint contract and manual check.
- `docs/phase-1.md`: Phase 1 scope and migration notes.
- `docs/verification.md`: recorded implementation verification results.

The obsolete `.phase1-backup/` and root `.vite/` cache were removed during cleanup.
The previous tracked implementation remains in Git history. The active source is
in frontend/src and backend/src; old IDE tabs pointing at root src files can be closed.
